Explainable XGBoost-Based Multiclass Obesity Prediction Framework

This figure shows an intelligent healthcare prediction framework that uses Bangladeshi demographic and lifestyle data from the Dhaka Obesity Dataset to classify multiple weight problem levels and combines system recognition, deep learning and interpretive AI techniques. Algorithms using XGBoost, random forest, logistic regression, SVM, LightGBM, CatBoost and deep neural networks (DNNs) have been applied to the weight problem classification, where XGBoost uses preprocessing techniques, including outline feature scaling, label magnitude encoding and SMOTE-based equal weighting. emphasis on important obesity-related tasks along with weight, height, age, family records, state-of-the-art AI-driven healthcare analytics demonstrates the effectiveness of integrating the use of Python, Scikit studies, XGBoost, TensorFlow/Keras and NumPy, Panda.
